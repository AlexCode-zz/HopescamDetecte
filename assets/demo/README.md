# Imagen de demostración

`ecografia_sintetica.png` es una imagen **sintética** usada por el modo
demostración de HopeScan. No corresponde a una persona real ni a un estudio
clínico.

Se deriva de un fixture de pruebas (`tests/fixtures/ood/accept/ultrasynth_1.png`)
y se versiona para que la app pueda probarse sin subir datos de pacientes. No
debe usarse como ejemplo clínico ni como evidencia de rendimiento del modelo.
